Telegram AI Personal Assistant

One chat that handles email, calendar and your spreadsheet, and answers questions from your own documents.

RAG

Document Knowledge Base Pipeline

Turns your files into a searchable knowledge base that an AI can answer from.

The problem

A general AI doesn't know your price list, policies or manuals, so it guesses.

What I built

A pipeline that pulls a file from Google Drive, splits the text into chunks, converts each chunk into OpenAI embeddings and stores them in a Supabase vector database. Any agent can then search it and answer from your real content.

  • GDDrive file
  • ✂Text splitter
  • AIEmbeddings
  • SBVector store

Built with: n8n, Google Drive, OpenAI Embeddings, Supabase Vector Store

Business workflow

Order System for a Cleaning Supplies Shop

Every new order is calculated, recorded and announced automatically, with no manual copying.

The problem

A small shop receives orders in different places, then adds up totals and notifies people by hand. It is slow and mistakes slip in.

What I built

An order form or webhook receives each order. The workflow calculates the total and delivery fee, appends it to a Google Sheet, sends the owner a Telegram alert, sends an email through Gmail and confirms to the sender.

  • { }Calculate
  • GSSheets
  • TGTelegram
  • MGmail
  • WRespond

Built with: n8n, Webhooks, JavaScript, Google Sheets, Telegram, Gmail
